# Heyfa — E-commerce UI (React)

This is a lightweight React frontend scaffold (no backend) implementing an e-commerce homepage UI inspired by the provided design.

Quick start

1. Install dependencies

```powershell
npm install
```

2. Run dev server

```powershell
npm run dev
```

This project uses Vite. It's focused on styles and UI (responsive layout, hero, categories, product cards). Images use Unsplash links — replace with your assets as needed.

Files of interest

- `index.html` — root HTML and fonts
- `src/main.jsx` — React entry
- `src/App.jsx` — main page composition
- `src/components/*` — UI components
- `src/index.css` — global and component styles
